## 1.1 什么是 OpenBB？

### 一句话定义

> **OpenBB 是一个开源的金融数据聚合平台，让你用一套统一的接口访问 30+ 个数据源。**

### 通俗理解

想象一下，你要获取股票数据：

- 从 Yahoo Finance 获取价格 → 需要学习 yfinance API
- 从彭博获取新闻 → 需要学习 Bloomberg API  
- 从 SEC 获取财报 → 需要学习 SEC API
- ……

每个数据源都有不同的 API、不同的数据格式、不同的认证方式。这就像你要去 10 个不同的超市买东西，每个超市的货架布局都不一样，结账方式也不同。

## 1.2 OpenBB 能做什么？

OpenBB 可以帮你获取各种金融数据，主要包括：

### 📈 股票数据

```python
# 获取苹果公司股票历史价格
from openbb import obb
data = obb.equity.price.historical("AAPL")
```

支持的数据类型：
- 历史价格（日/周/月）
- 实时报价
- 财务报表（收入表、资产负债表、现金流量表）
- 公司信息
- 分析师评级
- 内幕交易

### 🪙 加密货币数据

```python
# 获取比特币价格
data = obb.crypto.price.historical("BTC-USD")
```

支持的数据类型：
- 历史价格
- 实时行情
- 交易对搜索

### 📊 经济数据

```python
# 获取美国 GDP 数据
data = obb.economy.gdp.nominal(country="united_states")
```

支持的数据类型：
- GDP、CPI、失业率
- 利率、汇率
- 经济日历
- 央行数据

### 📰 新闻数据

```python
# 获取苹果公司相关新闻
data = obb.news.company(symbol="AAPL")
```

### 📉 衍生品数据

```python
# 获取期权链数据
data = obb.derivatives.options.chains(symbol="AAPL")
```

### 💹 ETF 数据

```python
# 获取 ETF 信息
data = obb.etf.info(symbol="SPY")
```

## 1.3 为什么选择 OpenBB？

### 对比：直接调用 API vs 使用 OpenBB

| 维度 | 直接调用各数据源 API | 使用 OpenBB |
|------|---------------------|-------------|
| **学习成本** | 高（每个 API 都要学） | 低（学一次，用所有） |
| **代码量** | 多（每个源写一套） | 少（统一调用方式） |
| **数据格式** | 各不相同 | 统一标准化 |
| **切换数据源** | 大量重构 | 改一个参数 |
| **维护成本** | 高 | 低 |
| **社区支持** | 分散 | 集中 |

### 实际例子

假设你要从 Yahoo Finance 切换到 FMP（Financial Modeling Prep）获取股票数据：

**不使用 OpenBB**：

```python
# 使用 yfinance
import yfinance as yf
ticker = yf.Ticker("AAPL")
data = ticker.history(period="1mo")

# 切换到 FMP 需要完全重写
import requests
url = "https://financialmodelingprep.com/api/v3/historical-price-full/AAPL"
response = requests.get(url, params={"apikey": "YOUR_KEY"})
data = response.json()  # 格式完全不同！
```

**使用 OpenBB**：

```python
from openbb import obb

# 使用 yfinance
data = obb.equity.price.historical("AAPL", provider="yfinance")

# 切换到 FMP，只需改一个参数！
data = obb.equity.price.historical("AAPL", provider="fmp")
```

## 1.4 架构一览

OpenBB 采用分层架构设计，让系统既灵活又易于扩展：

```
┌─────────────────────────────────────────────────────────────┐
│                    🏗️ OpenBB 架构简图                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                    你的应用                            │  │
│  │            (Python / REST API / CLI)                  │  │
│  └───────────────────────────┬───────────────────────────┘  │
│                              │                              │
│                              ▼                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                   OpenBB Platform                     │  │
│  │  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐  │  │
│  │  │ equity  │  │ crypto  │  │ economy │  │  news   │  │  │
│  │  │ (股票)  │  │(加密货币)│  │ (经济)  │  │ (新闻)  │  │  │
│  │  └─────────┘  └─────────┘  └─────────┘  └─────────┘  │  │
│  └───────────────────────────┬───────────────────────────┘  │
│                              │                              │
│                              ▼                              │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                   数据提供者层                         │  │
│  │                                                       │  │
│  │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐    │  │
│  │  │ FMP │ │Yahoo│ │ SEC │ │FRED │ │CBOE │ │ ... │    │  │
│  │  └─────┘ └─────┘ └─────┘ └─────┘ └─────┘ └─────┘    │  │
│  │                                                       │  │
│  │              30+ 数据提供者                            │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 三种使用方式

1. **Python SDK**：直接在 Python 代码中调用
2. **REST API**：通过 HTTP 接口调用，支持任何编程语言
3. **CLI**：命令行界面，快速交互式查询

## 1.5 适合谁使用？

### ✅ 量化研究员

- 快速获取历史数据进行回测
- 统一数据格式便于分析
- 支持多数据源交叉验证

### ✅ 数据分析师

- 一站式获取金融数据
- 直接输出 DataFrame，无缝对接 Pandas
- 丰富的可视化支持

### ✅ 金融开发者

- REST API 便于集成到应用
- 可扩展架构，轻松添加数据源
- 活跃的开源社区

### ✅ 金融学生/研究者

- 免费获取专业级数据
- 学习金融数据处理
- 实践量化分析技术
