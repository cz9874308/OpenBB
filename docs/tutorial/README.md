# 📚 OpenBB 新手教程

> 从零开始，轻松掌握 OpenBB 金融数据平台

---

## 🎯 课程简介

欢迎来到 OpenBB 新手教程！本教程专为**零基础用户**设计，通过 9 节课程带你从入门到精通。

无论你是量化研究员、数据分析师还是金融开发者，这套教程都能帮助你快速上手 OpenBB，获取全球金融数据。

## 📋 先决条件

在开始学习之前，请确保你具备以下基础：

### ✅ 必需

- **Python 基础**：了解变量、函数、列表、字典等基本概念
- **Python 3.9+**：已安装 Python 3.9 或更高版本
- **pip 包管理**：了解如何使用 pip 安装包

### 📌 推荐（非必需）

- **Pandas 基础**：了解 DataFrame 的基本操作
- **命令行基础**：了解如何在终端执行命令
- **金融基础知识**：了解股票、ETF 等基本概念

### 🔧 环境准备

```bash
# 检查 Python 版本（需要 3.9+）
python --version

# 检查 pip 是否可用
pip --version
```

## 💡 学习建议

1. **边学边练**：每课都有实践任务，一定要动手做
2. **循序渐进**：按顺序学习，不要跳课
3. **遇到问题**：先看常见问题，再查官方文档
4. **做好笔记**：记录关键概念和代码示例
